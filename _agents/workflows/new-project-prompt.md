# 新規プロジェクト開始プロンプト（スキル活用版）

おっしゃる通り、`_agents/skills/stable-gulp-coding/SKILL.md` というルールブック（スキル）が存在する最大のメリットは**「人間が毎回長々としたプロンプトを書かなくて済む」**ことです。

AIに新規プロジェクトのコーディングを依頼する際は、以下の非常にシンプルなプロンプトを投げるだけで、AIは勝手にルールを読み込んでから作業を開始します。（文脈によっては指示すら不要で自動で読み込みます）

```text
これから新しいWebサイトのコーディングをお願いします。
添付したデザインカンプを元に、このプロジェクトの `_agents/skills/stable-gulp-coding/SKILL.md` のルール（BEM、Margin-less Block、レイアウト責務分離など）に厳格に従ってHTMLとSCSSを作成してください。
まずは構成案（コンポーネントの分割案）を出してください。
```

## AIがこの問いかけで動ける理由

スキルのファイル群の中には、アーキテクチャや命名規則の「AIが守るべき絶対ルール」が全て言語化されています。
AIに「そのスキルファイルに従って」と指示するだけで、AIはそれを自動読み込みし、ご自身が設定した高品質なルールに沿ってコードを生成します。
